# GameHub

A browser-game directory with a community-dashboard inspired layout.

## Design
- Light grey page background, black text, pale grey cards and blue accents
- Featured-game hero, top navigation, game list, and right-hand sidebar
- Responsive layout for phones and desktops

## Features
- 30 browser games
- Search and category filters
- Favorites saved in local browser storage
- Game links open in a new tab and are hosted by their original providers

Some third-party game links may change or be unavailable depending on the provider. GameHub links out to the original sites and does not host their games.
